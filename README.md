## 🚀 Getting Started Locally

Get this absolute powerhouse running on your local machine in under 2 minutes.

### 1️⃣ Database Setup & Backend API
```bash
# Clone the repository
git clone https://github.com/anshumaan12-2003/healthcare-app.git
cd healthcare-app/backend

# Create your super-secret .env file
echo "DATABASE_URL=postgresql://postgres:password@localhost:5432/medicore" > .env
echo "JWT_SECRET=super_secret_dev_key" >> .env
echo "PORT=5000" >> .env

# Install dependencies, push the schema, and seed the database!
npm install
npx prisma db push
npm run db:seed

# Fire up the backend engine 🚀
npm run dev
```

### 2️⃣ Start the Frontend Matrix
```bash
# Open a new terminal tab
cd ../frontend

# Install dependencies
npm install

# Start the Vite dev server ⚡️
npm run dev
```
